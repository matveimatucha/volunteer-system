# Папка для медиа-ресурсов (картинок, логотипов и т.д.)

Сюда вы можете загрузить файлы для брендирования вашего сайта:

1. **`logo.png`** — логотип организации. Он автоматически отобразится в шапке главной страницы.
2. **`main-bg.jpg`** — общая фоновая картинка для шапки главной страницы.

Вы также можете указывать любые прямые ссылки на изображения из интернета (например, из ВК, Telegram или хостингов картинок) в панели администратора при редактировании каждого конкретного мероприятия.
